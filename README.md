# AGST Experimentation Wiki

Study notes for a graduate course on the principles of experimentation: probability, describing data, study design, inference, t-tests and one-way ANOVA, all in R. Written from first principles, as linked Obsidian notes, and published with [Quartz](https://quartz.jzhao.xyz).

- The notes are in `content/`. They are generated from a private Obsidian vault, so edit there and regenerate rather than editing `content/` directly.
- Every push to `main` rebuilds the site with GitHub Actions (`.github/workflows/deploy.yml`).
- Preview locally: `npm ci`, `npx quartz plugin install --from-config`, `npx quartz build --serve`.

The main textbook is Vu and Harrington (2020), *Introductory Statistics for the Life and Biomedical Sciences*, OpenIntro. Full references are on the site's References page. Quartz itself is MIT-licensed (`LICENSE.txt`).
